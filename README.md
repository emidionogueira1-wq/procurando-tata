# Procurando Tata

Jogo de navegador com os gatos Anakin e Alceu: Pela cidade, Labirinto dos ratos, Pet shop e Floresta encantada 3D.

Jogue em: https://emidionogueira1-wq.github.io/procurando-tata/

Controles: setas, OK/Enter/Espaço, X (bola de pelo), controle de videogame, controle remoto ou toque. F tela cheia, N som, M mapa.

Créditos: three.js (MIT), ZzFX por Frank Force (MIT).
